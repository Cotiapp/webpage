# CotiApp - Formaliza tu trabajo en segundos

La herramienta de cotización premium diseñada exclusivamente para los nuevos trabajadores independientes de Latinoamérica. Proyecta autoridad y profesionalismo en cada presupuesto.

## Características Principales

- **Creación rápida de PDFs:** Genera documentos con diseño editorial automático.
- **Gestión de clientes:** Directorio organizado de contactos e historial de facturación.
- **Multimoneda:** Adaptado para el mercado LATAM (USD, COP, EUR).
- **Control Freemium:** Comienza gratis con hasta 5 cotizaciones profesionales cada 365 días.

## Beneficios

- **Profesionalismo instantáneo:** PDFs de alta calidad que generan confianza.
- **Ahorro de tiempo:** Crea propuestas en minutos con plantillas inteligentes.
- **Control total:** Registro histórico de envíos y métricas desde un solo panel.
